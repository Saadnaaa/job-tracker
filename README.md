# Job Tracker — Job Application Management System

Job Tracker is a full-stack web application built with **Next.js, MongoDB, and JavaScript** to help job seekers organize and manage their job applications in one place. Instead of tracking applications manually in spreadsheets or notes, users can maintain a centralized record of the opportunities they have applied for and monitor their progress throughout the job search process.

## Features

- **Create Job Applications:** Add job applications with company name, job position, application URL, current status, and personal notes.
- **View Applications:** Display saved job applications in an organized list, making it easy to review application details.
- **Update Application Status:** Change the status of an application between Applied, Interview, Offer, and Rejected as the hiring process progresses.
- **Delete Applications:** Remove applications that are no longer needed, with a confirmation prompt to prevent accidental deletion.
- **MongoDB Database:** Store application data persistently using MongoDB and Mongoose.
- **Server Actions:** Handle application creation, retrieval, deletion, and status updates using Next.js Server Actions.
- **Form State Management:** Use React state to manage form inputs, loading states, and user interactions.
- **Toast Notifications:** Provide feedback for successful operations and errors using React Hot Toast.
- **Responsive UI Foundation:** Use Tailwind CSS and daisyUI to build a clean, modern interface that can be extended for different screen sizes.

## Tech Stack

- **Frontend:** Next.js App Router, React, JavaScript
- **Styling:** Tailwind CSS, daisyUI
- **Backend:** Next.js Server Actions
- **Database:** MongoDB Atlas, Mongoose
- **Notifications:** React Hot Toast
- **Development Tools:** ESLint, npm

## Project Goals

This project was developed as a practical full-stack learning project to apply modern Next.js concepts, database integration, reusable React components, asynchronous operations, input validation, and error handling in a real-world scenario.

The project also demonstrates a structured approach to organizing application logic, database models, server actions, and UI components in a maintainable codebase.

## Future Improvements

Potential enhancements include editing application details, searching and filtering applications, dashboard statistics, authentication, and more advanced application tracking features.

**Job Tracker** is a foundation for a practical job-search management tool and a portfolio project demonstrating full-stack JavaScript development with Next.js and MongoDB.
